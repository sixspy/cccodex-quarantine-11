## 试跑（dry-run）

打开试跑开关后，抓取调度不再咬正式规则：正式套规则须先敲定试跑，敲定后策略页采数改道到试跑钉点规则，双轨不并行。

- **试跑落点**：试跑当刻的「规则指纹 + 样本键」整笔落库（`trial_runs` 独立凭证），同一事务内写审计账册；落点已存在则拒覆写。
- **写锁**：同一策略同一时刻只允许一笔「试跑中」，部分唯一索引保证两侧并发争抢时仅一笔登记、另一笔中文回滚。
- **不误拦清洗编排**：规则号与试跑钉点一致时编排放行；只有「拧了」（钉点与凭证规则号不一致或悬空）才拦，并吐中文。
- **联验**：策略页亮试跑芯片与联验列，抓取列表亮试跑规则号；试跑后再抽一单编排核对（样本键对齐）。
- **只读口径**：`trial_mode` / `trial_scope` / `trial_rule_code` 在台参数页只读，只能由试跑操作改写。
